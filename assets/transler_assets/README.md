# Transler Assets

Individual PNG crops extracted from the generated Transler visual brand board.

- `brand/`: logo and app icon
- `mascot/`: mascot variants
- `features/`: feature icons
- `documents/`: document format icons
- `illustrations/`: hero and conceptual graphics
- `backgrounds/`: decorative backgrounds
- `components/`: upload, progress and status components

**Important:** These are raster crops, not original vector layers. Some have white/light
backgrounds or neighboring artwork from the composite source. They are suitable as
visual references and some directly as images, but need redrawing for crisp SVG,
true transparency, and production-ready icon sizing. Typography inside artwork
is not editable. Use as a starting asset pack, not as an official brand master.
