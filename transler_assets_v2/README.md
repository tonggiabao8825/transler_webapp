# Transler independent assets

All assets are independently authored SVGs, each with its own canvas and a 2x PNG export. None are cropped from a collage. The artwork is an original vector interpretation of the earlier direction, not a pixel-perfect replica.

Folders: brand, mascot, icons, file-types, languages, decorations, components, status, badges.

Note: language symbols are stylized chips, not accurate national flags. Wordmark uses Arial fallback.
